## What to build

Apply the Pattachitra visual language to the production navigation and footer without reducing access to search, theme controls, localisation, mobile navigation, contribution routes, or footer links. This gives the homepage and Tutorials route one coherent site frame.

## Acceptance criteria

- [ ] Desktop and mobile navigation retain every currently available route and utility control.
- [ ] Navigation and footer use the new Odia mark, palm-leaf palette, display typography, and decorative restraint without adding nested interactive elements.
- [ ] The mobile menu is keyboard operable, announces its state, and closes after navigation.
- [ ] Footer links, contribution path, and existing accessibility text remain present.
- [ ] The shared chrome has no horizontal overflow at 320px and works in light and dark theme modes if theme switching remains enabled.
