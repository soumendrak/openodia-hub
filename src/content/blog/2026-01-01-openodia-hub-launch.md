## What happened

OpenOdia Hub (openodia.com) went live — a unified web presence for the Odia open-source AI ecosystem. The site aggregates GitHub repositories, PyPI metadata, YouTube tutorials, community events (including live-scraped GDG/GDGoC events), and the Awesome-Odia-AI tools directory into a single, searchable platform.

## Why it matters

Before the hub, the Odia AI ecosystem was fragmented across GitHub, YouTube, PyPI, and community forums. OpenOdia Hub became the front door — a place where anyone can discover what exists, learn how to contribute, and find upcoming events.

## Features at launch

- **Projects**: Live GitHub repo aggregation across 5 Odia ML organizations
- **Tools Directory**: 60+ searchable Odia AI resources synced from Awesome-Odia-AI
- **Tutorials**: Aggregated YouTube content from 4 Odia AI channels
- **Events**: Community event calendar with live GDG/GDGoC scraping
- **Contributors**: Live contributor wall and leaderboard
- **Roadmap**: Public roadmap synced from GitHub Issues
